Claude (web or desktop)
  1. Settings, Connectors, Add custom connector.
  2. Name it Rewst MCP Apps Demo, paste the URL above, leave authentication empty. If it says it couldn't check the server, choose Continue anyway.
  3. In a new chat, turn it on from the tools menu.

Claude only reads a connector's tool list when it connects, so if the demo changes, remove it and add it again.

ChatGPT (paid plans)
  1. Turn on developer mode: Settings, then the Plugins (formerly Connectors) section, Advanced. On Business and Enterprise an admin has to allow it first.
  2. Add a custom MCP app named Rewst MCP Apps Demo, paste the URL above, and set authentication to none.
  3. In a new chat, pick it from the plugins menu in the message box.

OpenAI has moved these menus around a few times this year, so the names may be slightly different for you.

Microsoft 365 Copilot (cards included)

Copilot doesn't take a URL directly, so there's a ready-made agent you upload once. You need a Microsoft 365 Copilot license, and your tenant has to allow uploading custom apps (if it doesn't, a Teams admin can upload it for you).

  1. Download the agent (a small zip; don't unzip it).
  2. In Teams: Apps, Manage your apps, Upload an app, Upload a custom app. Pick the zip, then Add.
  3. Open Microsoft 365 Copilot (in Teams or at m365.cloud.microsoft/chat), pick Rewst MCP Apps Demo from your agents, and try one of its starter prompts. Allow it to connect when asked.

Copilot doesn't fill the cards in while the AI is still typing, and it won't follow a light/dark switch until the card reloads. Everything else works. To remove it later: Apps, Manage your apps, then the trash icon next to it.

Copilot Studio can connect to this server too (Tools, Add a tool, New tool, Model Context Protocol, the URL above, authentication None), but Microsoft lists cards inside Copilot Studio agents as still rolling out, so today you'll mostly get plain text there.

Why name it in your prompts: if you also have Rewst's real MCP server connected, the AI can't always tell which "Rewst" you mean. Saying "Rewst MCP Apps Demo" points it at this one. Asking "Rewst MCP Apps Demo, what can you see?" brings up the safety card.
