Privacy

This is a demo with made-up data. The server only receives what your AI sends it in a tool call. It doesn't store anything, has no database, doesn't log what you send, and makes no outbound network calls. It has no access to Rewst, Microsoft 365, your PSA or anything else.

Cloudflare, which hosts it, keeps basic request counts like it does for any website. If Rewst's own MCP server is connected in the same chat, the AI may send names from your tenant (like integration and workflow names) to draw a plan. The tools tell it never to send IDs, client or people names, emails or credentials, but don't send anything sensitive.

Ask the connector "what can this server see?" for the same details as a card.
